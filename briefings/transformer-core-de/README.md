# Transformer core materials briefing (Germany)

A standalone 9-slide deck for German transformer makers and labs, in the PRISM deck's look:
1920 × 1080 stage, Manrope and Geist Mono (bundled in `fonts/`), navy and paper slides.
Open `index.html` in a browser; `#5` opens slide 5, arrow keys move, and a phone held upright
gets the slides as one scrolling page. It is not part of the website build.

The headlines carry the argument on their own:

1. Better core materials for grid transformers.
2. Every link in the chain needs a better core. (material makers → transformer makers → grid operators)
3. Core loss has three parts. Each is a material property.
4. Every core material gives something up.
5. Customers want higher flux density.
6. Shown at pilot scale. Not yet for the grid.
7. Flux, loss and ease of making pull apart.
8. Alloy and anneal, designed together.
9. Develop a core material with us.

`node briefings/transformer-core-de/render.mjs` (after `npm ci`) writes PNGs of every slide to `renders/`.
