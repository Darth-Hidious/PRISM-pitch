# Logos

- `mirdyne-mark.svg`: the Mirdyne mark alone. Single ink, #171714. In a page, prefer the MirdyneMark component, which takes `currentColor`.
- `mirdyne-lockup-ink.png`: mark and wordmark in black, for `paper` grounds. Minimum height 28 px.
- `mirdyne-lockup-white.png`: mark and wordmark in white, for `navy` grounds and the footer band.

Clear space around a lockup: at least the height of the mark's notch on every side. Never recolour the PNGs, add effects or set the wordmark in another face.
