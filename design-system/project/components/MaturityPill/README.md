# MaturityPill

How far a capability has come, in four fixed words: In use, Prototype, In development, Target.

- In use: runs in current programmes. Prototype: PRISM software being matured from TRL 3 to 4. In development: being built. Target: where the platform is going, not claimed today.
- Put one on every capability claim on the website.

Props: `maturity` (`in-use` | `prototype` | `development` | `target`).
