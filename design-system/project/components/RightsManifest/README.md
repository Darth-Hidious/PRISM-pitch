# RightsManifest

The machine-readable rights that travel with a piece of evidence: owner, custodian, purpose, what may be derived, where it may go.

- `{allow: '...'}` renders in teal-text, `{deny: '...'}` in crimson-text.
- Caption example manifests "Illustrative" and use placeholder parties ("Customer A").

Props: `rows` ([key, string | {allow} | {deny}][]), `caption`, `note`.
