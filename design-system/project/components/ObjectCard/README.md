# ObjectCard

One object of the PRISM ontology, a Requirement, a Specimen, a Module, with its type, a few properties and its rights state.

- `type` is set in the data face ("Module · Evolver"). Keep properties to two or three short pairs.
- `emphasis` fills the card that anchors a group.
- Example objects carry "Illustrative" in a property; never invent measurements.

Props: `type`, `title`, `id`, `properties` ([key, value][]), `state`, `emphasis`.
