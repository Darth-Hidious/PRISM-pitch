# ProcessChain

Numbered steps joined by steel connectors, read left to right; the last step is filled because it is where the chain lands.

- Use for the PRISM loop: Requirement → Candidate → Physics → Coupon → Evidence.
- `loop` names the return path under the chain ("Learn: test data changes the next prediction").
- Up to six steps; each label one or two words, each detail one line.
- Stacks vertically below 860 px.

Props: `steps` ({`label`, `detail`}[]), `emphasizeLast` (default true), `loop`, `label` (accessible name).
