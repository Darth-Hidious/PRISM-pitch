# FooterBand

The navy band along the foot of every slide: company left, programme line centre, position right.

- Default left side is the Mirdyne mark and name; pass `left` to replace it.
- `right` holds the position ("03 / 12") and, in the live deck, the previous and next controls.
- On navy slides the band merges with the ground, as on the Briefing's dark slides.

Props: `left`, `middle` (default "PRISM · Freedom to build"), `right`.
