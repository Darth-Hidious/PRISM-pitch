# Timeline

A vertical run of dated events on one rule; `steel` dots for done, `crimson` for the current item, hollow for next.

- Use for programme sequences and roadmaps; one current item at most.
- The date column can hold a status word instead of a date (Active, Awarded, Next).

Props: `items` ({`date`, `title`, `detail`, `state`: `done` | `current` | `next`}[]), `label`.
