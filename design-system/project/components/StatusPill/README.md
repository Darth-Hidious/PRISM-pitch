# StatusPill

One or two words of programme status, in a tinted pill whose tone carries meaning.

- `accent`: Active, Awarded, Delivered. `teal`: Contracted, Pilot design. `crimson`: Interest (an early signal). `neutral` (dashed): Next.
- Always a word; colour never carries the status alone.
- For capability maturity use MaturityPill, which fixes the words.

Props: `children`, `tone` (`accent` | `teal` | `crimson` | `neutral`).
