# MirdyneMark

The Mirdyne mark, inline, filled with `currentColor` so it takes the colour of the text beside it.

- Set `color` with the same token as the adjacent text: `ink` on paper, `on-chrome` in the band.
- Pass `title=""` when a visible wordmark sits beside it, so screen readers do not hear "Mirdyne" twice.
- For the full lockup (mark and wordmark) use the Logos assets.

Props: `className`, `style`, `title` (default "Mirdyne").
