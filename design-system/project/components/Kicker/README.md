# Kicker

The wide-tracked capital label above every headline; on the website it is numbered ("02 · The platform").

- `accent` by default; `muted` for asides ("A precedent").
- One kicker per headline, never on its own.

Props: `children`, `tone` (`accent` | `muted`), `as` (`p` | `span` | `h2` | `h3`), `className`.
