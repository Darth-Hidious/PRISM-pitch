# RightsState

Where a piece of evidence may go: Private, Computable, Released or Public, each with its own glyph.

- Private: stays inside the organisation that produced it. Computable: approved workloads may compute on it; nobody inspects it. Released: an approved derivative shared with named parties. Public: deliberately published.
- The glyph carries the state without colour: filled square, half square, ring, dashed ring.

Props: `state` (`private` | `computable` | `released` | `public`), `label` (overrides the word).
