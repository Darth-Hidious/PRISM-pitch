# EvidenceLineage

The chain an engineering decision can be walked back along, from requirement to decision, each link named.

- Name every link with a verb phrase: motivates, instantiated as, produced, measured by, supports, justifies.
- The last node is filled: it is what the chain justifies.
- Put a rights state on each node when the view is about data rights.
- Label example lineages as illustrative.

Props: `nodes` ({`type`, `title`, `state`}[]), `links` (strings, one fewer than nodes), `label`.
